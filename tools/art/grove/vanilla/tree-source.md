# Vanilla tree sources

Original Terraria art by Re-Logic; these are not generated or ExampleMod art.
Source: General Sprites (1.3.5.3), extracted by CirnoTheSylveon:
https://www.spriters-resource.com/pc_computer/terraria/asset/113161/
Archive: https://www.spriters-resource.com/media/assets/110/113161.zip?updated=1755478352
Extracted only Images/Tiles_5.png, Images/Tree_Tops_0.png and
Images/Tree_Branches_0.png. Native frame compatibility was checked against
loaded tModLoader v2026.9.3.1/Terraria 1.4.4.9.

Files are stored unchanged. tools/build_camphor_assets.py changes exact RGB
palette entries, preserving alpha, dimensions, pixels outside the palette,
frame placement, all six wood shades and all three foliage variants. The
updated palette matches the grove grass/plant greens and warm dark bark.
There is no procedural mask filling, resizing or generated bark in this path.
